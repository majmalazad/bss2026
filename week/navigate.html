Navigating through the Labs

This guide explains how to access the practical environment before you start weekly lab work. Use it as a reference whenever a weekly lab asks you to open Netlab, Kali, or Wireshark. Apporto and local VirtualBox route (not supported in 2026-27 session) are included only as reference notes.

Lab environment: start and access your tools

This lab gets you into the practical environment before you run tools. Use Netlab first. Apporto and local VirtualBox route (not supported in 2026-27 session) are included only as reference notes.

Learning outcomes

  • Schedule and enter a Netlab pod.
  • Launch the CMP5358/Kali environment.
  • Identify Apporto and local VirtualBox route (not supported in 2026-27 session) as reference notes only.
  • Release the VM/pod when you finish.

A. Start a Netlab pod

Open https://netlab.catcemea.org.uk/home.cgi

and sign in with your university username and password.
Select the relevant class or search for CMP5358. Choose the CMP5358 software security class when it appears.
Choose the lab content. For the first part of the module, use the customised BCU CMP5358 VM where instructed.
Use the drop-down action menu, select Schedule Lab, choose your time slot, and press Submit.
When the booking starts, click Enter Lab. Select Kali and log in with username kali and password kali.

B. Use NDG pre-built labs

Inside CMP5358, select NDG Ethical Hacking V2 Series 1 or Series 2 when your tutor asks you to use it.
Open the drop-down menu beside the chosen lab, for example Web Testing, and select Schedule Lab.
Use Preview Lab when you want to read the instructions before reserving the pod.
Choose the date and time. Use the scroll and next-pod controls if the first slot is not suitable.
After your session, cancel or de-allocate the pod if you no longer need it. This allows other students to use it.

C. Apporto and local VirtualBox route (not supported in 2026-27 session)

Reference only (not supported in 2026-27 session): Open https://bcu.apporto.com/home in Firefox, Chrome or Edge and sign in with your university account.
Launch Modular Cyber Lab (Tutors). Use the left-side icons to open Terminal or Wireshark.
To start a VM from terminal, run VirtualBox, select the VM and start it.
On a lab PC fallback route, press the TIC button, press Enter at the login screen, search for Oracle VM VirtualBox, and start the CMP5358 or Kali VM.
If you cannot see the VM, open C:\Virtual Machine and import or start the VM file provided for the lab.
Common issue: if you open Wireshark inside a VM, generate traffic inside the same VM. Opening a browser on the host machine may not create traffic in the VM capture.
