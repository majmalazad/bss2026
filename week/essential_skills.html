Professional capability

From 12 weeks of practical learning to professional capability

The weekly labs took you from networking and operating-system foundations to vulnerability testing, secure development and professional disclosure. Each topic reflects tasks performed in security operations, penetration testing, application security, vulnerability management and cyber risk roles.

Across the module, you learned how systems communicate, how applications process untrusted input, how attackers exploit weak controls and how professionals validate, report and fix security problems. The labs also trained you to work within authorisation, establish a normal baseline, collect reliable evidence, explain business impact and retest mitigations. These are core habits in real-world cyber security.

Foundation skills

Networking and protocols

What you should master: TCP/IP, DNS, HTTP, TLS, routing, switching, ports, firewalls and packet analysis.

Why it matters: You need this knowledge to trace traffic, recognise abnormal behaviour and investigate network attacks.

Cyber security area: Network security, security operations, infrastructure security and network forensics.

How you will use this skill at work: In employment, you will analyse packet captures, map communication paths, investigate suspicious connections and help tune network controls.

Relevant job roles: SOC Analyst, Network Security Analyst, Network Security Engineer, Penetration Tester and Security Operations Engineer.

Operating systems and command line

What you should master: Linux and Windows processes, services, permissions, files, logs and system-administration commands.

Why it matters: Most security tools and investigations require you to understand how operating systems store data and enforce access.

Cyber security area: Endpoint security, system hardening, incident response, digital forensics and infrastructure security.

How you will use this skill at work: In employment, you will harden hosts, inspect processes and services, search logs, collect evidence and support incident containment.

Relevant job roles: Cyber Security Analyst, Incident Responder, Digital Forensics Analyst, Endpoint Security Engineer and Security Administrator.

Programming, scripting and automation

What you should master: Python, Bash or PowerShell for reading code, processing data, automating repetitive tasks and creating safe testing utilities.

Why it matters: Automation improves consistency and helps you analyse large datasets, logs and security findings efficiently.

Cyber security area: Security automation, detection engineering, penetration testing, malware analysis and application security.

How you will use this skill at work: In employment, you will parse logs, automate repetitive checks, create safe proof-of-concept scripts and connect security tools through APIs.

Relevant job roles: Security Automation Engineer, Detection Engineer, Penetration Tester, Application Security Engineer and Security Researcher.

Identity, cryptography and data protection

What you should master: Authentication, authorisation, least privilege, key management, encryption, hashing, certificates and privacy controls.

Why it matters: These controls protect accounts, communications and sensitive data across systems and organisations.

Cyber security area: Identity and access management, public-key infrastructure, cloud security, privacy and data protection.

How you will use this skill at work: In employment, you will review access policies, troubleshoot authentication, assess certificate and key use, and protect sensitive data.

Relevant job roles: IAM Analyst, IAM Engineer, PKI Engineer, Cloud Security Engineer, Data Protection Analyst and Security Architect.

Build and test securely

Secure engineering

Develop the skills used by application security, penetration testing, product security, cloud security and DevSecOps teams.

Engineering and assessment skills

Web, API and database security

What you should master: Requests, sessions, authentication, access control, input validation, databases and common web vulnerabilities.

Why it matters: Organisations depend on web applications and APIs, which remain frequent targets for attackers.

Cyber security area: Application security, API security, product security, database security and offensive security.

How you will use this skill at work: In employment, you will inspect requests, test authentication and access control, assess sessions and input validation, and advise developers on fixes.

Relevant job roles: Application Security Analyst, Web Application Penetration Tester, API Security Engineer, Product Security Engineer and Security Consultant.

Secure coding, threat modelling and SDLC

What you should master: Identify threats early, review code, apply secure design principles and integrate security checks throughout development.

Why it matters: Preventing weaknesses during design and development costs less than fixing them after deployment.

Cyber security area: Application security, product security, software assurance, DevSecOps and secure architecture.

How you will use this skill at work: In employment, you will model threats, review designs and code, define security requirements and add security checks to development pipelines.

Relevant job roles: Application Security Engineer, Product Security Engineer, Secure Software Engineer, Threat Modeller and DevSecOps Engineer.

Vulnerability assessment and penetration testing

What you should master: Plan authorised tests, use scanners carefully, validate findings manually, assess impact and retest corrections.

Why it matters: Professional testing requires evidence and judgement rather than accepting automated tool output as proof.

Cyber security area: Offensive security, vulnerability management, security assurance and technical consultancy.

How you will use this skill at work: In employment, you will scope assessments, run tools safely, validate scanner results, demonstrate impact, prioritise fixes and complete retesting.

Relevant job roles: Vulnerability Analyst, Penetration Tester, Red Team Associate, Security Consultant and Vulnerability Management Specialist.

Cloud, container and DevSecOps security

What you should master: Cloud identities, storage, networks, virtual machines, containers, CI/CD pipelines and infrastructure configuration.

Why it matters: Security teams must protect rapidly changing cloud services and development pipelines without blocking delivery.

Cyber security area: Cloud security, platform security, container security, infrastructure-as-code assurance and DevSecOps.

How you will use this skill at work: In employment, you will review cloud identities, storage and networks, assess containers and infrastructure code, and secure CI/CD workflows.

Relevant job roles: Cloud Security Analyst, Cloud Security Engineer, DevSecOps Engineer, Platform Security Engineer and Container Security Specialist.

Detect, investigate and recover

Defence and response

Use evidence to identify malicious activity, contain incidents and support recovery in SOC, threat-hunting and DFIR roles.

Operational security skills

Security monitoring and threat intelligence

What you should master: Analyse logs and alerts, use SIEM concepts, recognise indicators of compromise and relate activity to attacker techniques.

Why it matters: Effective monitoring helps you detect attacks early and prioritise the events that need investigation.

Cyber security area: Security operations, detection engineering, threat hunting and cyber threat intelligence.

How you will use this skill at work: In employment, you will triage alerts, investigate logs, write detection rules, hunt for attacker behaviour and enrich incidents with threat intelligence.

Relevant job roles: SOC Analyst, Threat Hunter, Detection Engineer, Cyber Threat Intelligence Analyst and Security Monitoring Engineer.

Incident response and digital forensics

What you should master: Prepare, identify, contain, eradicate and recover from incidents while preserving evidence and documenting decisions.

Why it matters: A disciplined response reduces harm and supports technical, legal and organisational review.

Cyber security area: Incident response, digital forensics, cyber defence, evidence handling and recovery.

How you will use this skill at work: In employment, you will preserve and analyse evidence, contain compromised systems, support recovery and document decisions for technical and legal review.

Relevant job roles: Incident Response Analyst, DFIR Analyst, Digital Forensics Examiner, CSIRT Analyst and Cyber Defence Analyst.

Evidence before conclusion

Correlate multiple data sources, record your assumptions and distinguish confirmed activity from plausible explanations that still need validation.

Professional practice skills

Risk, governance, law and ethics

What you should master: Assess likelihood and impact, understand policies and standards, respect scope and authorisation, and follow relevant legal and ethical duties.

Why it matters: Technical actions must support organisational risk decisions and remain lawful, proportionate and accountable.

Cyber security area: Governance, risk and compliance, security assurance, audit, privacy and regulatory compliance.

How you will use this skill at work: In employment, you will assess cyber risks, map controls to standards, support audits, review policies and help organisations meet legal and regulatory duties.

Relevant job roles: GRC Analyst, Cyber Risk Analyst, Security Auditor, Compliance Analyst, Information Security Officer and Privacy Analyst.

Communication, teamwork and continuous learning

What you should master: Write clear reports, explain risk to technical and non-technical audiences, collaborate effectively and keep your knowledge current.

Why it matters: Security professionals succeed when they turn evidence into decisions and adapt to new technologies and threats.

Cyber security area: A cross-cutting capability required in technical operations, consultancy, management, research and security leadership.

How you will use this skill at work: In employment, you will write findings, brief technical and business stakeholders, coordinate remediation and explain why a security decision matters.

Relevant job roles: Security Consultant, Cyber Security Analyst, Security Team Lead, Technical Account Security Specialist and most graduate cyber security roles.

Professional behaviours to demonstrate

  • Confirm scope and permission before testing.
  • Use the least intrusive method that answers the security question.
  • Record evidence, limitations and uncertainty clearly.
  • Protect sensitive information in notes, screenshots and reports.
  • Explain risk in language appropriate for the audience.
  • Accept feedback and update your methods as technology changes.
